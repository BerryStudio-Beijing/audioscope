# AudioScope Web UI — 0.8-alpha

Precision Instrument dashboard for AudioScope by BerryStudio, built against the
BerryStudio UI / MasterLens 3.0 visual reference in the same workspace.

## Run

```bash
# From alpha/
python3 -m http.server 8124 --bind 127.0.0.1 --directory web
# open http://127.0.0.1:8124/
```

The source UI includes a deterministic synthetic snapshot, so it renders without
the C++ engine. For live updates, `ui --live` serves this directory and pushes a
snapshot over WebSocket every 500 ms:

```bash
./build/audioscope-alpha ui --out build/ui
python3 -m http.server 8125 --bind 127.0.0.1 --directory build/ui
# open http://127.0.0.1:8125/
```

`ui` copies this directory and replaces `<!--DATA-->` with
`window.AUDIOSCOPE_DATA`, generated by the C++ core (scope waveform, spectrum,
THD metrics, XY points, channels, repair plan). With `--live` it also injects
`window.AUDIOSCOPE_LIVE = true`; `js/app.js` then connects to `ws://<host>/ws`
and repaints the current page in place.

## Design baseline

- 1120 × 700 logical canvas, scaled as one surface; 4 px grid.
- Geist (embedded), CJK fallback PingFang SC / Microsoft YaHei UI.
- Dark default; light is independently designed, not inverted.
- One accent (`#819e90` dark / `#356d56` light); warn/bad only for semantics.
- Three materials: flat data, raised cards, recessed plots/inputs.
- Header 64, rail 48, body 460, params 96, footer 32.
- Charts keep a dark graphite measurement surface in both themes.
- No pure black/white surfaces, no neon/glass/gradients as decoration.
- All numbers tabular; negative values use U+2212.

## Pages

| Page | Content |
|---|---|
| 波形 | peak/RMS/frequency/crest/Vpp/clip, waveform, timebase |
| 频谱 | THD/THD+N/SNR/SINAD/SFDR/ENOB, log spectrum, harmonics |
| 相位 | phase/gain/polarity, XY density, fitted ellipse |
| 测量 | 8-channel table, limits, verdict |
| 维修 | tape plan steps, pass/fail, thresholds |
| 报告 | JSON/HTML/PDF report list |
| 校准 | profile fields, confidence, voltage warning |
