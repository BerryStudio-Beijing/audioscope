## 阻断级限制

1. **没有硬件保护前端。** 软件只能预警、锁存、静音，不能阻止过压损坏声卡。
   不要接市电、喇叭输出、未衰减胆机输出。
2. **Windows 仍是 WinMM 2ch。** 不是 WASAPI，不支持 >2ch；延迟较高。
3. **Windows 未在真机音频设备上验证。** CI 编译、CTest 与安装包生成通过，
   但没有在 Windows 上实际打开 `AudioScope.exe` 测过录音/播放。
4. **macOS 与 Windows 二进制未签名、未公证。** Gatekeeper / SmartScreen 可能提示。
5. **实时桥已移除。** 0.9 不再提供 Web UI / WebSocket；所有界面都是本地原生绘制。
6. **真实 DUT 闭环需要手动接线。** Loopback 用默认输出→默认输入，
   需要物理或虚拟回环；不是校准过的 DUT 测量。
7. **没有原生菜单栏之外的复杂交互。** 页面切换、按钮、键盘快捷键可用；
   缩放/游标/拖动等交互仍待后续版本。
8. **没有设备选择 UI。** 采集/回环使用系统默认输入/输出。
9. **PDF 是 3 页摘要。** 波形/频谱各一页；没有前后对比、曲线叠加或模板化报告。
10. **电压不可用。** 没有校准向导 UI；未校准时只显示 dBFS。
11. **Windows 安装包是 Inno Setup EXE**，安装到 Program Files；没有 MSI/ARM64。
12. **macOS 最低 12.0；Windows 最低 10。**

## 下一版必须解决

1. WASAPI 共享模式 + Windows >2ch，真机验证。
2. 设备选择、采样率切换、热插拔提示。
3. 原生游标/缩放/平移、每通道量程。
4. 校准向导 + 设备库。
5. 真实 DUT 闭环与前后对比、曲线叠加。
6. 签名/公证与安装包自动更新。
7. 硬件前端参考设计。
8. Windows 的逐字字距：GDI+ `DrawString` 不支持 letter-spacing，当前只在 macOS
   生效；若必须一致，需要在 Windows 用逐字绘制或 DirectWrite（会牵动渲染架构）。
