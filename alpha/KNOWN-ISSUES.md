# AudioScope by BerryStudio — 1.0 Known Issues

> 版本：`1.0.0` · 日期：2026-11-07
> 这是 **原生 UI 正式版**，但还不是完整校准/维修工作台。

## 1.0 已修（相对 0.9.3-beta）

- **CH2 独立**：两通道各自统计、各自削波；报告使用每通道数据。
- **实际采样率**：统计 / FFT / THD / 相位 / 时间轴 / loopback 跟随设备实际率。
- **模拟结果标注**：Tape Plan 显示 `SIMULATED` / `DEMO PASS`；导出报告降为
  WARN 并带模拟备注。
- **Loopback**：只称 connectivity，不再暗示 DUT 合格。
- **Windows 设备 ID**：WinMM 按真实设备编号打开，不再误用列表下标。

## 0.9.3 已修（相对 0.9.2）

- **信号发生器**：9 种波形（正弦/方波/三角/锯齿/白噪/粉噪/对数扫频/脉冲/
  阶跃），电平默认钳在 −20 dBFS，方波/锯齿带 PolyBLEP，噪声可复现。
- **设备选择**：波形页可循环选择输入/输出设备，采集、发生器与 loopback
  都使用选中设备。
- **热插拔**：每 2 s 枚举；选中输入消失时停止采集并提示，不静默切换。
- **FFT 尺寸**：频谱页 1024–16384 可切换，历史缓冲扩到 16384。

## 0.9.2 已修（相对 0.9.1）

- **Windows**：读数用真减号 U+2212；示波器 ±1.0 / 0 / −1.0 与 0 / 7.5 / 15 ms
  刻度；频谱 0…−100 dB 与 20 Hz / 1 kHz / 20 kHz 刻度；报告页空状态；
  示波器页常驻安全声明；报告表列宽按卡片宽度比例；页眉/页脚统一等宽排印。
- 更正：Windows 三张表原本就是列坐标实现（0.9.1 记录写错了）。

## 0.9.1 已修（相对 0.9.0-alpha.1）

- 标签页指示线不再"从左边飞过来"：时间驱动 140 ms ease-out，从当前位置出发；
  首帧/减少动态直接落位（`tests/test_nav.c` 锁住行为）。
- 窗口任意比例等比自适应，resize 立即重绘，鼠标命中与绘制共用几何。
- 刷新率 60 Hz；图表单路径描边；颜色/字体行/渐变缓存；FFT/THD/相位 20 Hz。
- 浅色模式下示波器/频谱/XY 保持深石墨测量面。
- 表格列对齐、真减号 −、轴刻度、报告空状态、示波器页常驻安全声明。
- Windows：深石墨测量面、同一套导航缓动、16 ms 定时器、XY 单折线。

## 阻断级限制

1. **没有硬件保护前端。** 软件只能预警、锁存、静音，不能阻止过压损坏声卡。
   不要接市电、喇叭输出、未衰减胆机输出。
2. **Windows 仍是 WinMM 2ch。** 不是 WASAPI，不支持 >2ch；延迟较高。
3. **Windows 未在真机音频设备上验证。** CI 编译、CTest 与安装包生成通过，
   但没有在 Windows 上实际打开 `AudioScope.exe` 测过录音/播放。
4. **macOS 与 Windows 二进制未签名、未公证。** Gatekeeper / SmartScreen 可能提示。
5. **实时桥已移除。** 0.9 不再提供 Web UI / WebSocket；所有界面都是本地原生绘制。
6. **真实 DUT 闭环需要手动接线。** Loopback 用默认输出→默认输入，
   需要物理或虚拟回环；不是校准过的 DUT 测量。
7. **没有原生菜单栏之外的复杂交互。** 页面切换、按钮、键盘快捷键可用；
   缩放/游标/拖动等交互仍待后续版本。
8. **设备选择是基础版。** 可循环选择输入/输出并记忆稳定 id，但没有设备
   详情、采样率切换或通道映射；Windows 仍固定 2ch，热插拔后需手动重新采集。
9. **PDF 是 3 页摘要。** 波形/频谱各一页；没有前后对比、曲线叠加或模板化报告。
10. **电压不可用。** 没有校准向导 UI；未校准时只显示 dBFS。
11. **Windows 安装包是 Inno Setup EXE**，安装到 Program Files；没有 MSI/ARM64。
12. **macOS 最低 12.0；Windows 最低 10。**

## 下一版必须解决

1. WASAPI 共享模式 + Windows >2ch，真机验证。
2. WASAPI 共享/独占与采样率切换；设备详情、通道映射与热插拔后的显式恢复。
3. 原生游标/缩放/平移、每通道量程。
4. 校准向导 + 设备库。
5. 真实 DUT 闭环与前后对比、曲线叠加。
6. 签名/公证与安装包自动更新。
7. 硬件前端参考设计。
8. Windows 的逐字字距：GDI+ `DrawString` 不支持 letter-spacing，当前只在 macOS
   生效；若必须一致，需要在 Windows 用逐字绘制或 DirectWrite（会牵动渲染架构）。
