## 3. 新增命令

```text
wow [seconds] [--synthetic --wow PCT --flutter PCT]
crosstalk [seconds] [--synthetic]
impedance --r R --vsrc V --vdut V | --simulate Z
azimuth [seconds] [--synthetic --phase DEG]
compare <before.json> <after.json>
```

说明：

- `wow` 输出 **RMS %**；`--wow/--flutter` 注入的是 **peak %**，RMS ≈ peak/√2。
- `crosstalk` 需要只驱动 CH1；`--synthetic` 注入 −60 dB。
- `impedance` 使用 `Z = R·Vdut/(Vsource−Vdut)`。
- `azimuth` 用 10 kHz L/R 相位；接近 0° 且 L+R 最大为佳。
- `compare` 读取报告 JSON 的首通道数值，输出差值。

## 4. 测试记录

环境：macOS 26（Apple Silicon），Apple clang 21；Windows 交叉编译 mingw-w64。

### 4.1 macOS

```bash
cd alpha
make clean
make mac
make test
```

结果：

- `selftest`：**42/42 通过，0 failure**
- `scope` / `fft` 冒烟通过
- `ringtest` 通过
- `wow 10 --synthetic --wow 0.3 --flutter 0.1`：wow ≈ 0.216% RMS、flutter ≈ 0.059% RMS（对应注入 0.3%/0.1% peak）
- `crosstalk 2 --synthetic`：−60.00 dB
- `impedance --r 1000 --vsrc 1 --simulate 32`：32.00 Ω
- `azimuth 2 --synthetic --phase 10`：10.00°
- `compare`：两份真实测量报告峰值/RMS/频率/削波差值输出
- `measure --channels all`：8 通道逐通道报告
- `xy` / `drift` / `spectrogram` 回归通过

### 4.2 Windows

```bash
make win
file build/audioscope-alpha.exe
```

结果：PE32+ x86-64，链接 `WINMM.dll`，静态链接。**未在真实 Windows 上运行验证**；WinMM 仍为 2ch。

## 5. 已知限制

- 没有原生 GUI；仍是 ASCII TUI。
- Windows 2ch / WinMM，不是 WASAPI。
- 真实跨设备漂移未接线。
- wow/flutter 用零交叉瞬时频率，需要干净 3 kHz 测试带。
- 阻抗是手动串联电阻法。
- 没有 THD/IMD、维修模板、PDF。
- 没有硬件前端。

## 7. 安全声明

软件只能预警、锁存、静音，不能保护声卡免受高压损坏。高压/未知信号必须经过受保护前端；不要接市电、喇叭输出、未衰减胆机输出。
