# AudioScope by BerryStudio 0.9-alpha — 原生 UI 与打包

> 版本：`0.9.0-alpha.1` · 日期：2026-11-07
> 主题：移除 Web UI，改为 macOS `.app` + Windows 安装包；补多页 PDF 与 loopback。
> 分支：`v0.9`；前一版：`v0.8.0-alpha.1`。

## 1. 目标与取舍

用户要求：不再用 Web UI，所有界面本地重写；Windows 可安装，macOS 是 `.app`。
0.9 的交付范围因此是：

- 原生 macOS AppKit/CoreGraphics 七页应用，`.app`；
- 原生 Windows Win32/GDI+ 七页应用 + Inno Setup 安装包；
- 多页 PDF；
- Loopback（输出→输入）测量；
- 保留 CLI 作为测量/回归入口。

WASAPI、设备选择、校准向导、签名/公证仍是后续版本；它们需要 Windows 真机或
额外的产品设计，不在本切片内假装完成。

## 2. 结构

| 文件 | 作用 |
|---|---|
| `src/app/native_model.cpp/hpp` | 双端共享数据模型与引擎：合成/采集、FFT、THD、XY、维修计划、loopback、导出 |
| `src/ui/native_ui.c/h`、`native_theme.c/h` | 从 v1.1 沿用并整理的 CoreGraphics/CoreText 即时模式控件与 token |
| `src/ui/native_pages.cpp/hpp` | macOS 七页布局与交互 |
| `src/platform/macos/native_app.mm` | AppKit 窗口/视图/定时器/对话框；`--shot` 离屏渲染 |
| `src/platform/win/native_app_win.cpp` | Win32 窗口 + GDI+ 七页布局 |
| `packaging/macos/Info.plist` | `.app` 元数据、麦克风用途说明 |
| `packaging/windows/AudioScope.iss` | Inno Setup 安装包 |
| `assets/fonts/` | Geist OTF + OFL |

## 3. 实现

### 3.1 macOS

- 1120×700 逻辑画布，窗口缩放时等比 letterbox；鼠标坐标反算。
- 七页共享同一 model；30 Hz 定时器刷新；`--shot` 用 2× 位图离屏渲染。
- 采集/回环使用原生 `NSAlert` 确认；错误显示 `as_audio_last_error()`。
- 主题切换、键盘 `1–7`/Space/C/R/E/T。

### 3.2 Windows

- Win32 窗口 + GDI+ 双缓冲；DPI aware；同一套 token/布局。
- 采集/回环同样先确认；导出后 `ShellExecuteW` 打开 PDF。
- Inno Setup：Program Files、开始菜单、可选桌面图标、卸载器。

### 3.3 PDF 与 loopback

- `as_pdf_new_page`/`as_pdf_polyline`；`as_report_write_pdf_ex` 输出 3 页
  （摘要 / 波形 / 频谱），原子写入。
- Loopback：默认输出播放 −20 dBFS 1 kHz，默认输入录 2 s，算 RMS/THD，
  PASS 条件 `level > −60 dBFS && THD < 1 %`。

## 4. 测试与调试

- macOS：`make test` → 52 项 selftest、ringtest、`AudioScope --shot` 七页
  全部生成；`make app` 链接无警告。
- `--shot` 截图逐页检查：scope/spectrum/XY/measure/repair/reports/calibration。
- 发现并修复：
  - 原生 `.mm` 中 `theme_*` 因头文件缺少/错位 `extern "C"` 而链接失败；
  - `HEADER_H`/`NAV_H` 宏与页面常量冲突；
  - `std::string` 传给 C 版 `ui_text` 的编译错误；
  - `--shot` 目录不存在导致首张 PNG 写失败；PNG finalize 偶发失败加重试；
  - 合成信号三次谐波过高导致维修计划误报 FAIL（已降到 THD≈0.03 %）。
- CI：macOS 15 + windows-2022 在 commit `4d1e485` 上 configure / build / ctest /
  package 全绿（run 42361615105）。Windows 侧修掉的编译问题：
  - `gdiplus.h` 需要先包含 `<objidl.h>`（`IStream` 未定义）；
  - `gd::SolidBrush b(gd::Color(c));` 是最烦人的解析（被当成函数声明），
    改为花括号初始化；
  - `PixelFormat32bppPARGB` 是宏，不能写成 `gd::PixelFormat32bppPARGB`；
  - `as_linear_to_db` 是全局 C 符号，不是 `audioscope::` 成员。

- Release run 42362010289：macOS `.app` + `.dmg`、Windows `setup.exe` +
  portable zip、`SHA256SUMS.txt` 全部发布为 pre-release：
  <https://github.com/BerryStudio-Beijing/audioscope/releases/tag/v0.9.0-alpha.1>。

## 6. 安全声明

软件只能预警、锁存、静音，不能保护声卡。高压/未知信号必须经过受保护前端；
不要接市电、喇叭输出、未衰减胆机输出。
