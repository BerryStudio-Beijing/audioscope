# AudioScope by BerryStudio 0.9.3-beta — 信号发生器与音频 I/O

> 版本：`0.9.3-beta.1` · 日期：2026-11-07
> 主题：把“只读监测”补成“能主动给信号 + 能选设备”，并让 FFT 尺寸可调。
> 分支：`main`；前一版：`0.9.2-beta.1`。

## 1. 目标

0.9 的七页只能看，维修页只有一个固定 1 kHz 的 loopback。0.9.3 补三件
维修台必须有的能力，且不改变安全语义：

1. **信号发生器**：维修需要扫频、方波、噪声、脉冲和阶跃，不只是 1 kHz 正弦。
2. **设备选择**：采集 / 输出必须能指定设备，而不是永远系统默认。
3. **FFT 尺寸**：低频频谱要更细的窗，瞬态要看更短的窗。

非目标：WASAPI、>2ch、独占模式、采样率切换、校准向导、游标/缩放。

### 2.1 波形与安全默认

- 波形：正弦、方波、三角、锯齿、白噪、粉噪、对数扫频、单位脉冲、阶跃。
- 方波/锯齿用 PolyBLEP 降低混叠；噪声固定种子，**同参数逐位可复现**。
- 电平预设 `−60 / −40 / −30 / −20 dBFS`；`gen_config()` 在
  `gen_hot_allowed == false` 时把电平钳到 **−20 dBFS**（安全默认）。
- 输出启动时按 **200 ms 线性淡入**（CoreAudio/WinMM 回调内逐样本），避免刚
  打开设备就硬切到满电平；关闭时复位淡入状态。
- 频率/周期预设：`20 Hz … 20 kHz`、`50 ms … 2 s`；扫频终点仍可在 model 中设。

### 2.2 音频 I/O

- UI 的 `sel_in/sel_out` 是 `AsDeviceInfo` 全表下标，`-1` = 系统默认。
- 选中设备用稳定 id（CoreAudio device id / WinMM index 字符串）记忆；
  重新枚举后按 id 找回，找不回退回系统默认。
- 采集与发生器共用一个 `AsAudio`：打开方向由 `capture_` 与 `gen_on` 决定；
  `-2` 表示该方向不打开（沿用 0.7 起的约定）。
- Windows 端修正：列表下标不等于 WinMM 设备 ID，`as_audio_open()` 现在按
  `in%u` / `out%u` 解析，避免选中非默认设备时打开错设备。
- 输入设备消失：**停止采集**并显示 `input device lost — capture stopped`；
  不静默切到别的设备（`AGENTS.md` 硬约束）。

### 2.3 FFT 尺寸

- 频谱页循环 `1024 / 2048 / 4096 / 8192 / 16384`。
- 历史缓冲扩到 16384；频谱、THD、相位共用尾部 N 点窗。
- 切换后下一帧立即重算（`slow_count_` 归零）。

## 5. 安全声明

默认输出从 −20 dBFS 起；UI 不提供“解锁更高电平”的入口；发生器关闭且不在
采集时立即释放音频设备。软件仍然不能保护声卡，接未知电平时必须用受保护的
前端。
