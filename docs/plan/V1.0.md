# AudioScope by BerryStudio 1.0 — 可信测量正式版

> 版本：`1.0.0` · 日期：2026-11-07
> 主题：把 0.9.3 的发生器/设备能力与一组“结果可信度”修正一起交付。
> 前一版：`0.9.3-beta.1`（本地完成、未发布）。

## 1. 版本边界

1.0 是**正式版**，但按路线图仍只覆盖 M0/M1 的一部分：

- 已经可信：数据来源（Synthetic/Capture）、双通道独立、实际采样率、
  模拟/实测区分、安全默认（−20 dBFS、200 ms 淡入、clip 锁存显示）。
- 尚未完成：WASAPI、>2ch、采样率切换 UI、校准向导、游标/缩放、
  前后对比、签名/公证、Windows 真机音频验证。
- Tape Plan 明确是夹具演示，不是 DUT 测量。

## 2. 本版实现

| 任务 | 改动 | 文件 |
|---|---|---|
| T06 双通道独立 | CH2 不再由 CH1 减 0.9 dB；两通道各自统计/削波；`NativeChannel` 保存 `AsStats` | `native_model.hpp/.cpp` |
| T05 采样率贯通 | 统计 / FFT bin 映射 / THD / 相位 / 时间轴 / loopback 使用 `model->fs`；`build_bins(fs)` | `native_model.*` |
| T01/T02 结果来源 | `plan_simulated`；屏幕 `SIMULATED` / `DEMO PASS`；报告降 WARN + `notes` | `native_model.*`、双端 UI |
| T03 口径 | 示波器时间窗随采样率；频谱保持 peak-relative 标注；Vpp 标 `FS` | 双端 UI |
| 设备 | IN/OUT 选择、稳定 id、热插拔、WinMM 设备 ID 解析 | `native_model.*`、`audio_winmm.c` |
| 发生器 | 9 波形、PolyBLEP、固定种子、−20 dBFS 上限、200 ms 淡入 | `core/generator.*`、后端 |
| 发布 | 版本 1.0.0、release notes、README 功能化、CI/Release 走正式版 | 全部 |

## 3. 验收与证据

- macOS：`make -B test` → **63 项 selftest + 12 项 navtest + 10 项 modeltest +
  ringtest + 七页 `--shot`**，0 failure，`-Wall -Wextra` 零警告。
- 截图：`build/shot-100`（暗）与 `build/shot-093-light`（明）；示波器时间窗、
  设备行、GENERATOR、`SIMULATED` 标记均在卡片内。
- 引擎冒烟：设备枚举、FFT 切换、发生器关闭、I/O 应用。
- 报告：`--export-test` 写出 PDF；模拟计划带 `SIMULATED` 备注。
- Windows：用 mingw-w64 做交叉编译检查；最终以 CI 的 MSVC + CTest 为准。
- 发布：tag `v1.0.0` → `release.yml` 产出 macOS `.app`/`.dmg`、Windows
  `setup.exe`/zip、`SHA256SUMS.txt`，**不标记 prerelease**。

## 4. 安全声明

- 默认输出 −20 dBFS，200 ms 淡入；发生器关闭即释放设备。
- 未校准不显示电压；模拟/夹具结果不发布为实测 PASS。
- 软件不能保护声卡：未知、高压或功率输出必须经过受保护前端。

## 5. 已知限制

见 `alpha/KNOWN-ISSUES.md`。最重要的三条：Windows 仍是 WinMM 2ch；
没有校准向导；没有游标/缩放/前后对比。
