## 3. 新增命令

```text
thd [seconds] [--synthetic --freq HZ --level DBFS --thd PCT]
imd [seconds] [--synthetic --standard smpte|din]
sweep [--start DBFS --end DBFS --step DB --csv FILE]
```

- `thd` 用 Hann 窗 FFT；基波、2–10 次谐波、噪声/杂散分别统计。
- `thdn` 使用谐波 + 噪声；SNR 使用远离载波的噪声；SINAD 使用谐波 + 噪声。
- `imd` SMPTE：60 Hz + 7 kHz；DIN：250 Hz + 8 kHz；统计 f2 ± k·f1 边带。
- `sweep` 目前用合成信号（真实设备需输出→DUT→输入闭环）。

## 4. 测试记录

环境：macOS 26（Apple Silicon），Apple clang 21；Windows 交叉编译 mingw-w64。

### 4.1 macOS

```bash
cd alpha
make clean
make mac
make test
```

结果：

- `selftest`：**44/44 通过，0 failure**
- `scope` / `fft` 冒烟通过
- `ringtest` 通过
- `thd 2 --synthetic --level -6 --thd 0.1`：THD 0.1000%，THD+N 0.1212%，SNR 63.29 dB
- `imd 2 --synthetic`：IMD 0.1316%（注入约 0.1%）
- `sweep --start -40 --end 0 --step 6`：输出表格
- `sweep --csv`：CSV 列 `level_dbfs,thd_pct,thdn_pct,snr_db,sinad_db`
- 0.4 回归：wow/flutter、crosstalk、impedance、azimuth、compare、measure 8ch、xy、drift、spectrogram

### 4.2 Windows

```bash
make win
file build/audioscope-alpha.exe
```

结果：PE32+ x86-64，链接 `WINMM.dll`，静态链接。**未在真实 Windows 上运行验证**。

## 5. 已知限制

- 没有原生 GUI；仍是 ASCII TUI。
- Windows 2ch / WinMM，不是 WASAPI。
- THD 是单音 FFT；没有 THD vs 频率、没有扫频。
- `sweep` 目前只支持合成信号。
- IMD 只做 SMPTE/DIN；没有 CCIF/DIM 全套。
- 没有维修模板、PDF、THD vs 频率。
- 没有硬件前端。

## 7. 安全声明

软件只能预警、锁存、静音，不能保护声卡免受高压损坏。高压/未知信号必须经过受保护前端；不要接市电、喇叭输出、未衰减胆机输出。
