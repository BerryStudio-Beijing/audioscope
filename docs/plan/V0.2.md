## 3. 新增命令

```text
modes
check [seconds] [--synthetic]
calibrate [dir] --device NAME --channel N --gain DB --pad DB --rate HZ
                --dbfs -20 --measured-vrms V --confidence measured|datasheet|assumed
calibs [dir]
measure [seconds] --cal FILE --mode M --channel 0|1 --repeat N
                  --max-vpp V --min-rms V --max-clip N --out DIR
```

已有命令也升级：

- `monitor`：输入模式、SafetyGuard 预检、clip 锁存、可选校准显示电压。
- `tone`：默认 −20 dBFS 限幅，`--allow-loud` 才放开。
- `safety`：新增 clip feed 与量程建议演示。
- `selftest`：覆盖输入模式、clip feed、校准 pad/rate、报告 JSON/HTML、判定。

## 4. 测试记录

执行环境：macOS 26（Apple Silicon），Apple clang 21；Windows 交叉编译使用 mingw-w64。

### 4.1 macOS

```bash
cd alpha
make clean
make mac
make test
```

结果：

- `selftest`：34 项全部通过（0 failure）。
- `scope` / `fft` 冒烟通过。
- `ringtest`：通过。
- `measure` 实测（默认输入、1 s、inst 模式、无校准）：输出 WARN（未校准 + 低信号），生成 JSON/HTML/session.jsonl。
- `calibrate` + `calibs`：写入并列出 profile。
- `safety`：clip feed 进入 FAULT；probe 无 FE 被阻断。
- `check --synthetic`：建议 Line Pro，不自动切换。

### 4.2 Windows

```bash
make win
file build/audioscope-alpha.exe
```

结果：PE32+ x86-64，链接 `WINMM.dll`，静态链接。**未在真实 Windows 上运行验证**；CI workflow 已覆盖构建/ctest。

### 4.3 已知未测

- Windows 真机音频（WinMM）运行。
- 真实校准精度（需要万用表/参考源）。
- 双端同一 WAV 的一致性。
- 长时间 xrun/内存稳定性。

## 6. 安全声明

0.2-alpha 仍是预发布版。软件只能预警、锁存、静音，不能保护声卡免受高压损坏。高压/未知信号必须经过受保护前端；不要接市电、喇叭输出、未衰减胆机输出。
