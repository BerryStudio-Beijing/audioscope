# AudioScope by BerryStudio 0.7-alpha — 实现与测试记录

> 版本：`0.7.0-alpha.1` · 日期：2026-11-07
> 主题：按同工作区 **BerryStudio UI / MasterLens 3.0 复刻设计标准**重做前端视觉。
> 分支：`v0.7`；前一版：`v0.6.0-alpha.1`。

---

## 1. 本版目标

把 AudioScope 的 UI 从 ASCII TUI 扩展为一套**可评审的 Precision Instrument Web 仪表盘**，并保留 C++ 测量核心作为数据源：

- 设计 token、材质、排印、网格对齐 `berrystudio-ui/design-system`。
- 1120×700 逻辑画布；暗色默认、明色独立设计；图表保持深石墨测量面。
- 七个模块：波形、频谱、相位、测量、维修、报告、校准。
- `audioscope-alpha ui` 把 C++ 核心的快照注入 Web UI；无网络、无第三方运行时。

## 3. 实现

### 3.1 Web UI

- `alpha/web/index.html`：1120×700 外壳、深链接、`<!--DATA-->` 注入点。
- `alpha/web/styles/tokens.css`：BerryStudio 语义 token。
- `alpha/web/styles/app.css`：布局、材质、按钮、表格、弹窗、图表容器。
- `alpha/web/js/app.js`：页面渲染、Canvas 图、主题、快捷键、弹窗、导出。
- `alpha/web/assets/fonts/`：Geist 字体 + OFL。
- `alpha/web/scripts/shoot.sh`：2240×1400 截图。
- `alpha/web/docs/screens/`：本版参考截图。

### 3.2 `audioscope-alpha ui`

```bash
./build/audioscope-alpha ui --out build/ui
# 复制 web/，把 <!--DATA--> 替换为 C++ 生成的 window.AUDIOSCOPE_DATA
python3 -m http.server 8125 --bind 127.0.0.1 --directory build/ui
```

快照包含：

- `scope.waveform`（720 点连续波形）、peak/RMS/freq/crest/Vpp/clip；
- `spectrum.freqs/db`（220 个对数点）、THD/THD+N/SNR/SINAD/SFDR/ENOB；
- `xy.points`（1600 点，45° / +3 dB）；
- `channels`（8 通道）；
- `repair`（tape 计划 4 步）；
- `reports` / `calibration`。

`--live` 明确未接线，仍生成合成快照并打印警告。

## 5. 已知限制

- Web UI 是**本地只读快照**，不是实时 WebSocket 音频流；实时测量仍走 CLI。
- 没有原生 CoreGraphics/Direct2D GUI。
- Windows 仍 WinMM 2ch，不是 WASAPI。
- 维修计划只跑合成验证；真实 DUT 闭环未接线。
- PDF 单页摘要。
- 无硬件前端。

---

## 6. 下一版建议（0.8-alpha）

1. 实时 WebSocket / 原生 Canvas 桥。
2. WASAPI 共享模式 + Windows >2ch。
3. 真实 DUT 闭环（输出→DUT→输入）。
4. 多页 PDF + 曲线叠加。
5. 可编辑 JSON 维修计划。
6. 硬件前端参考设计。

## 7. 安全声明

软件只能预警、锁存、静音，不能保护声卡免受高压损坏。高压/未知信号必须经过受保护前端；不要接市电、喇叭输出、未衰减胆机输出。
