# AudioScope by BerryStudio 0.9.1-beta — 交互与性能修正

> 版本：`0.9.1-beta.1` · 日期：2026-11-07
> 主题：不改功能范围，修 0.9 原生界面的动画、缩放、帧率、排印与浅色模式测量面。
> 分支：`main`（直接提交，不另开分支）；前一版：`0.9.0-alpha.1`。

## 1. 目标与取舍

0.9 把 Web UI 换成原生界面后，视觉方向对了，但交互层有几处明显问题：

1. 导航指示线用"每帧向目标靠近 32%"的写法，叠加 30 fps 定时器，换页时会
   从上一页缓慢滑过——用户看到的就是"无论从哪里点，指示线都从左边飞过来"；
2. 窗口缩放几何只在 `drawRect` 里算，改窗口大小后鼠标命中仍用旧值；
3. 30 fps 且每帧重建颜色/字体行/渐变，720 点波形逐段描边，掉帧；
4. 浅色模式下示波器、频谱、XY 的测量面跟着卡片变亮，曲线的对比关系反了；
5. 表格靠拼空格对齐，比例字体表头与等宽数值永远对不齐；数字用 ASCII 连字符。

0.9.1 只做这五类修正，不新增测量能力，也不假装完成 WASAPI / 校准向导。

### 2.1 指示线动画

```c
/* 换页：从"当前显示位置"出发，目标按最终 index 计算 */
u->nav_from_x = u->nav_x;  u->nav_t0 = u->t;  u->nav_animating = 1;
/* 每帧：k = (t - t0) / MOTION_FAST; e = 1 - (1-k)^3 */
```

- 首帧、`g_reduce_motion`、目标未变：直接落位，不产生"从左飞来"的过渡；
- 动画时长与帧率解耦：60 fps 和 5 fps 都是 140 ms 结束；
- 状态属于 `UI` 实例，不再被同一函数的其它调用点污染。

### 2.2 性能

| 项 | 0.9 | 0.9.1 |
|---|---|---|
| 刷新率 | 30 Hz（`scheduledTimer`，默认 runloop mode） | 60 Hz（common modes） |
| 波形描边 | 720 次 `stroke` | 1 条 `CGPath` |
| XY | 512 个 `FillEllipse` / `ui_dot` | 1 条折线 |
| 颜色 | 每个图元 `CGColorCreate` + 色彩空间 | 96 项缓存 |
| 文本 | 每帧重建 `CFAttributedString` | 160 项 `CTLine` 缓存 |
| 渐变 | 每张卡片每帧重建 | 按主题缓存 2 个 |
| 引擎分配 | 每帧 3 个 `std::vector` | 0（成员缓冲复用） |
| FFT/THD/相位 | 每帧 3 次 4096 点 | 20 Hz（每 3 帧） |

## 3. 测试

```bash
cd alpha
make test        # 52 项 selftest + scope/fft + ringtest + navtest + 七页 --shot
```

- `tests/test_nav.c`：12 项断言全绿（从当前位置出发 / 半程在中间 / ease-out
  过半 / 精确落位 / 低帧率不变时长 / reduce-motion 直接落位）。
- `--shot` 七页在暗、明两个主题下重新生成并逐张检查：浅色主题的测量面保持
  深石墨，轴刻度、表格列、空状态、安全声明均按预期渲染。
- `-Wall -Wextra` 零警告。

## 5. 安全声明

本次改动只碰呈现与动画，不改变任何安全不变量：预检、clip 锁存、100 ms
静音、−20 dBFS 输出限制、未校准不显示电压都保持原样。软件仍然不能保护声卡。
