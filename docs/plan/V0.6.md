## 3. 新增命令

```text
templates
repair --template quick|pedal|tape|mixer|headphone [--out DIR]
freqsweep [--start HZ --end HZ --points N --csv FILE]
```

- `repair` 目前只跑合成验证；`--live` 明确未接线。
- `measure` 现在同时写 `.json`、`.html`、`.pdf`。
- PDF 是单页 Helvetica 摘要；HTML 仍是 canonical。
- `freqsweep` 默认 20 Hz–20 kHz 对数 10 点；20 kHz 的谐波超出 Nyquist，THD 会显示 0。

## 4. 测试记录

环境：macOS 26（Apple Silicon），Apple clang 21；Windows 交叉编译 mingw-w64。

### 4.1 macOS

```bash
cd alpha
make clean
make mac
make test
```

结果：

- `selftest`：**47/47 通过，0 failure**
- `scope` / `fft` 冒烟通过
- `ringtest` 通过
- `repair --template tape`：Wow 0.2121% / Flutter 0.0587% / Azimuth 10.00° / THD 0.1000%，PASS
- `repair --template mixer`：THD/IMD/Crosstalk −60 dB，PASS
- `measure 0.5 --channels 0`：生成 JSON/HTML/PDF
- `freqsweep 20..20k`：表格 + CSV
- PDF：`file` 报告 `PDF 1.4, 1 pages`；`qlmanage` 成功渲染为 PNG
- 0.5 回归：THD 0.1000%、IMD 0.1316%、wow/flutter、crosstalk、impedance、azimuth、measure 8ch、xy、drift、spectrogram

## 5. 已知限制

- 没有原生 GUI；仍是 ASCII TUI。
- Windows 2ch / WinMM，不是 WASAPI。
- 维修计划只跑合成验证；真实 DUT 闭环未接线。
- PDF 单页，无图表/多页/曲线叠加。
- `freqsweep` 用合成信号；真实闭环扫频未做。
- 没有硬件前端。

---

## 6. 下一版建议（0.7-alpha）

1. 原生 Canvas（CoreGraphics + Direct2D）+ 缩放/双光标。
2. WASAPI 共享模式 + Windows >2ch。
3. 真实 DUT 闭环（输出→DUT→输入）。
4. 多页 PDF + 曲线叠加。
5. 可编辑 JSON 维修计划。
6. 硬件前端参考设计。

---

## 7. 安全声明

软件只能预警、锁存、静音，不能保护声卡免受高压损坏。高压/未知信号必须经过受保护前端；不要接市电、喇叭输出、未衰减胆机输出。
