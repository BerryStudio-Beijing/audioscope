## 3. 新增命令

```text
xy [seconds] [--simulate --phase DEG --gain DB --drift PPM] [--ch1 N --ch2 N]
drift [seconds] [--simulate PPM] [--live]
spectrogram [seconds] [--synthetic] [--channel N]
measure [seconds] --channels all|0,1 ...
```

已有命令升级：

- `devices` 显示输入/输出通道数。
- `measure` 支持最多 8 通道同时测量，报告 JSON/HTML 多行。
- `monitor` 支持任意输入通道。

## 4. 测试记录

环境：macOS 26（Apple Silicon），Apple clang 21；Windows 交叉编译 mingw-w64。

### 4.1 macOS

```bash
cd alpha
make clean
make mac
make test
```

结果：

- `selftest`：**39/39 通过，0 failure**
- `scope` / `fft` 冒烟通过
- `ringtest` 通过
- `xy --simulate --phase 45 --gain 3`：读数 45.00° / 3.00 dB，Lissajous 点阵正常
- `drift 5 --simulate 100`：读数 100.00 ppm
- `spectrogram 1 --synthetic`：峰值行 ≈ 1014.6 Hz，热力图输出
- `measure 1 --channels all`：8 通道逐通道读数与 JSON/HTML 报告
- `devices`：Studio 1824c 显示 in=18/out=18，取前 8 路

### 4.2 Windows

```bash
make win
file build/audioscope-alpha.exe
```

结果：PE32+ x86-64，链接 `WINMM.dll`，静态链接。**未在真实 Windows 上运行验证**；WinMM 仍为 2ch。

### 4.3 CI

GitHub Actions（run 42285889795）：

- macOS 15：configure / build / ctest / package 全部通过。
- windows-2022：MSVC 2022 configure / build / ctest / package 全部通过。

## 5. 已知限制

- 没有原生 GUI；仍是 ASCII TUI。
- Windows 2ch / WinMM，不是 WASAPI。
- 真实跨设备漂移未接线；同设备 CH1/CH2 共享时钟。
- Lissajous 无余晖/椭圆拟合/频率比自动识别。
- 热力图无余晖/光标/导出。
- 无硬件前端。

---

## 6. 下一版建议（0.4-alpha）

1. 原生 Canvas（CoreGraphics + Direct2D）+ 缩放/双光标。
2. WASAPI 共享模式 + Windows >2ch。
3. 真实跨设备/聚合设备漂移。
4. Lissajous 余晖/椭圆拟合/频率比。
5. 热力图光标/PNG/CSV 导出。

## 7. 安全声明

软件只能预警、锁存、静音，不能保护声卡免受高压损坏。高压/未知信号必须经过受保护前端；不要接市电、喇叭输出、未衰减胆机输出。
