# AudioScope by BerryStudio 0.9.2-beta — Windows 排版对齐

> 版本：`0.9.2-beta.1` · 日期：2026-11-07
> 主题：把 0.9.1 在 macOS 上的排版修正补到 Windows；功能与安全语义不变。
> 分支：`main`；前一版：`0.9.1-beta.1`。

## 1. 目标

0.9.1 只做了 macOS 的交互/排印修正，Windows 仍是 0.9 的呈现。0.9.2 的目标是
**两端读起来像同一台仪器**，并且只改呈现层，不碰测量与安全逻辑：

1. Windows 读数仍是 ASCII 连字符，与 macOS 的真减号不一致；
2. 两端图表都没有轴刻度（0.9.1 只在 macOS 补了）；
3. Windows 报告页没有空状态、示波器页没有常驻安全声明；
4. Windows 报告表用绝对偏移（330 / 450），卡片宽度一变就失去比例；
5. 页眉/页脚的品牌、版本、状态行在两端的行高与字体角色不一致。

## 2. 实现

| 文件 | 改动 |
|---|---|
| `src/platform/win/native_app_win.cpp` | `pretty_minus()` + `fmt`/`fmt_signed`；示波器/频谱轴刻度与安全区；报告空状态；示波器安全声明；报告表按比例列宽；页眉三行（品牌 20px / 版本 Mono / 状态右对齐 272px）；页脚统一 Mono；页眉底部发丝线 |
| 版本文件 | `VERSION`、`core/api.h`、`CMakeLists.txt`、`Info.plist`、`AudioScope.iss` → `0.9.2-beta.1` |

### 2.1 轴刻度

- 示波器：Y 轴 `+1.0 / 0 / −1.0`（绘图区左留 34 px），X 轴 `0 / 7.5 / 15 ms`；
- 频谱：Y 轴 `0 … −100 dB`（右对齐 36 px 槽），X 轴 `20 Hz / 1 kHz / 20 kHz`
  三点定位（取代原来用空格拼一行的写法，窗口变化时不会错位）。

### 2.2 空状态与常驻声明

报告页：56 px 圆角图标块 + `No reports yet` / 如何导出 / 报告不外传三行，
居中显示。示波器页左下：分区分隔线 + `SAFETY` + 两行说明，与 macOS 一致。

### 2.3 关于字距（有意不做）

GDI+ 的 `DrawString` 不支持 letter-spacing。要做到与 macOS 相同的逐字字距，
只能逐字绘制（每帧上千次 DrawString，60 fps 下不现实）或改用 DirectWrite
（会牵动渲染架构）。因此 **Windows 不加逐字字距**，依靠行高、列坐标与等宽
数字保持秩序；限制写进 `KNOWN-ISSUES.md`。

## 3. 验证

- macOS：`make test` → 52 项 selftest + ringtest + 12 项 navtest + 七页 `--shot`
  全绿；本版未改 macOS 渲染，截图与 0.9.1 一致。
- Windows：本机无 MSVC/mingw，**以 CI 为准**（`alpha.yml` 在 windows-2022 上
  configure / build / ctest / package）。
- 发布：tag `v0.9.2-beta.1` → `release.yml` 产出 mac `.app`/`.dmg`、
  Windows `setup.exe`/便携 zip、`SHA256SUMS.txt`。

## 4. 未做

- WASAPI、设备选择、热插拔、游标/缩放/平移、校准向导、签名/公证；
- Windows 真机音频验证；
- Windows 逐字字距（见 §2.3）。

## 5. 安全声明

只改呈现。预检、clip 锁存、100 ms 静音、−20 dBFS 输出限制、未校准不显示电压
全部未动；软件仍然不能保护声卡。
