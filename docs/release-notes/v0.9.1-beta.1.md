## 修了什么

- **标签页指示线**：时间驱动（140 ms ease-out），从当前位置滑向目标；
  首帧与"减少动态"直接落位。不再出现"无论点哪里都从左边飞过来"。
- **窗口等比自适应**：任意窗口比例按 1120×700 缩放并居中；resize 立即重绘，
  鼠标命中与绘制用同一份几何；letterbox 外边取主题底色。
- **帧率与性能**：30 → 60 Hz；波形/频谱/XY 单路径描边；颜色、字体行、
  渐变缓存；引擎不再每帧分配；FFT/THD/相位降到 20 Hz。
- **浅色模式**：示波器、频谱、XY 的测量面固定深石墨，曲线与网格对比不反转。
- **排印**：Brand 角色、按钮 Label 角色、ASCII 字距 0.02–0.06em（中文不加宽）、
  Label 与 Value 共用基线、数字用真减号 −。
- **表格与刻度**：测量/维修/报告三张表固定列坐标；示波器 ±1.0 / 0 / −1.0 与
  0 / 7.5 / 15 ms；频谱 0…−100 dB 与 20 Hz / 1 kHz / 20 kHz。
- **空状态**：报告页三行空状态；示波器页常驻安全声明。
- **Windows 同步**：深石墨测量面、同一套导航缓动、16 ms 定时器、XY 单折线。

## 快捷操作

`1–7` 切页，`Space` 保持，`C` 采集，`R` 跑维修计划，`E` 导出报告，`T` 切主题。

## 验证

- macOS 本机：`make test` → 52 项 selftest、ringtest、**12 项导航动画回归**、
  `AudioScope --shot` 七页离屏渲染全绿；`make app` 链接无警告。
- 截图逐页检查暗/明两个主题。
- CI：macOS + windows-2022 的 configure / build / ctest / package 通过后才打包。

## 已知问题（与 0.9 相同）

- Windows 仍是 WinMM 2ch，WASAPI 与 >2ch 未实现；Windows 未在真机音频验证。
- 没有设备选择 UI、校准向导、游标/缩放/平移。
- Loopback 需要手动接线，不是校准过的 DUT 测量。
- 二进制未签名；软件不能保护声卡，高压/未知信号必须经过受保护前端。

完整限制见 `alpha/KNOWN-ISSUES.md` 与 `docs/plan/V0.9.1.md`。
