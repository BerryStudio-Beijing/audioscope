# AudioScope by BerryStudio 0.8.0-alpha.1 — Live Bridge

> 发布日期：2026-11-07 · 平台：macOS 12+ arm64 / Windows 10/11 x64
> 本版是 **0.8-alpha 的第一个切片**：把 0.7 的只读 Web UI 接上本地实时桥。

| macOS 12+ arm64 | `AudioScope-0.8.0-alpha.1-macos-arm64.zip` |

## 这版有什么

- **本地实时桥**：`audioscope-alpha ui --live` 在 `127.0.0.1` 上起一个自带的
  HTTP/1.1 + WebSocket 服务，不用再另开 `python3 -m http.server`。
- 浏览器连接 `ws://127.0.0.1:<port>/ws`，每 500 ms 收到一份快照并原地刷新；
  顶部显示 `LIVE / 连接中 / 离线`，断线按 0.5 s→8 s 退避重连。
- 快照与静态 `ui` 共用同一个 builder：波形、频谱、THD/SNR、XY、通道、维修计划。
- 默认数据源是**合成信号**（标注 `live · synthetic`）；`--capture` 才打开真实输入，
  打开失败会打印原因并回退，不静默假装有信号。
- 零第三方依赖；服务只 bind loopback，拒绝跨站 WebSocket Origin。
- 新增 `ui --live --smoke`，HTTP GET + WebSocket 握手 + 首帧都在 `make test` / CTest 里。

## 快速开始

```bash
# macOS
unzip AudioScope-0.8.0-alpha.1-macos-arm64.zip
./audioscope-alpha version
./audioscope-alpha ui --live --port 8125
# 打开 http://127.0.0.1:8125/

# Windows（PowerShell）
Expand-Archive AudioScope-0.8.0-alpha.1-windows-x64.zip -DestinationPath AudioScope
cd AudioScope
.\audioscope-alpha.exe ui --live --port 8125
```

`--capture [--device N]` 打开真实输入；macOS 会请求麦克风权限。`Ctrl-C` 停止服务。

## 已知问题

- **没有原生 GUI**：前端仍是本地 Web UI。
- **Windows 仍是 WinMM 2ch**：WASAPI 共享模式与 >2ch 尚未实现。
- **实时桥默认合成源**：`--capture` 未在授权环境做端到端采集验证。
- **多页 PDF / 曲线叠加、真实 DUT 闭环、真实跨设备漂移** 未实现。
- macOS / Windows 二进制**未签名、未公证**；Gatekeeper / SmartScreen 可能提示。
- 软件不能保护声卡。高压/未知信号必须经过受保护前端；不要接市电、喇叭输出或未衰减胆机输出。

## 安全与隐私

- 无遥测、无账号、无云服务；实时桥只监听 loopback。
- 未校准只显示 dBFS；电压必须带 `measured / datasheet / assumed` 置信度。
- 完整限制见 zip 内 `KNOWN-ISSUES.md` 与 `docs/plan/V0.8.md`。
