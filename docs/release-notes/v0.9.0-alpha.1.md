## 这版有什么

- **原生 macOS `.app`**：AppKit + CoreGraphics + CoreText，1120×700，
  Geist 字体内嵌，暗/明主题，七页：波形、频谱、相位、测量、维修、报告、校准。
- **原生 Windows 应用 + 安装包**：Win32 + GDI+ 双缓冲，DPI aware，同一套
  Precision Instrument token 与七页布局；Inno Setup 安装到 Program Files，
  开始菜单快捷方式、卸载器。
- **多页 PDF**：摘要 + 波形图 + 频谱图（原子写入）。
- **Loopback**：−20 dBFS / 1 kHz 输出→输入，读回 RMS 与 THD；需手动确认与接线。
- **真实数据路径**：采集显式 opt-in（默认合成数据并标注）；没有自动切换。
- **零 Web**：没有 WebView、HTTP、WebSocket、遥测或第三方运行时。

## 快捷操作

界面左下/右侧按钮；键盘：`1–7` 切页，`Space` 保持，`C` 采集，`R` 跑维修计划，
`E` 导出报告，`T` 切主题。

## 验证

- macOS 本机：`make test` → 52 项 selftest、ringtest、`AudioScope --shot`
  七页离屏渲染全绿；`make app` 链接无警告。
- CI：macOS 15 与 windows-2022 上 configure / build / ctest 通过后才打包；
  本 release 的 `.app`/安装包由该工作流生成。

## 已知问题

- **Windows 仍是 WinMM 2ch**：WASAPI 与 >2ch 未实现。
- **Windows 未在真机音频上验证**：CI 只覆盖编译、CTest、打包。
- **没有设备选择 UI**：采集/loopback 用系统默认设备。
- **没有校准向导**：未校准只显示 dBFS，电压隐藏。
- **没有游标/缩放/平移**：七页是只读监测 + 几个动作按钮。
- **Loopback 需要手动接线**；不是校准过的 DUT 测量。
- **软件不能保护声卡**：高压/未知信号必须经过受保护前端；不要接市电、
  喇叭输出或未衰减胆机输出。

## 安全与隐私

- 无网络、无遥测、无账号；报告只写本地 `Application Support/AudioScope/reports`。
- 输入模式不自动切换；采集/loopback 都需要确认。
- 完整限制见 `KNOWN-ISSUES.md` 与 `docs/plan/V0.9.md`。
