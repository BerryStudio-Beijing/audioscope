## 修了什么（Windows）

- **真减号**：读数使用 `−`（U+2212），不再出现 ASCII 连字符。
- **示波器刻度**：`+1.0 / 0 / −1.0` 与 `0 / 7.5 / 15 ms`，绘图区左留安全区。
- **频谱刻度**：`0 … −100 dB` 与 `20 Hz / 1 kHz / 20 kHz` 三点定位。
- **报告空状态**：图标块 + 三行文案（发生了什么 / 下一步 / 不外传）。
- **示波器安全声明**：左下角常驻。
- **表格与页眉页脚**：报告表列宽按卡片比例；页眉品牌/版本/状态三行对齐；
  页脚三段统一等宽 Mono。

## 已知限制

- GDI+ 的 `DrawString` 不支持 letter-spacing：**逐字字距只在 macOS 生效**。
- Windows 仍是 WinMM 2ch，未在真机音频验证；无设备选择、校准向导、游标缩放。
- 二进制未签名；软件不能保护声卡，高压/未知信号必须经过受保护前端。

完整限制见 `alpha/KNOWN-ISSUES.md` 与 `docs/plan/V0.9.2.md`。
