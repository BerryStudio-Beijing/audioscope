# AudioScope by BerryStudio 1.0.0

首个正式版：七页原生测量界面、9 波信号发生器、设备选择、FFT 尺寸与本地报告。

## Highlights

- **可信结果**：CH1/CH2 独立统计；实际采样率贯通统计 / FFT / THD / 相位 /
  时间轴 / loopback；Tape Plan 明确标记 `SIMULATED`，报告降为 WARN。
- **信号发生器**：正弦、方波、三角、锯齿、白噪、粉噪、对数扫频、单位脉冲、
  阶跃；PolyBLEP；固定种子噪声；默认 −20 dBFS，200 ms 淡入。
- **设备与采样**：输入/输出选择、稳定 id、热插拔检测、FFT 1024–16384。
- **原生双端**：macOS AppKit/CoreGraphics `.app` / `.dmg`；Windows Win32/GDI+
  `setup.exe` / 便携 zip；无 WebView、无网络、无遥测。
- **报告**：PDF + JSON + HTML；模拟结果带备注与 WARN。

## Known limits

- Windows 仍是 WinMM 2ch；WASAPI、独占模式、>2ch 未实现。
- 没有校准向导、游标/缩放/平移、修复前后对比。
- 设备选择是基础版（无采样率切换 / 通道映射）。
- 二进制未签名、未公证。

见仓库内 `alpha/KNOWN-ISSUES.md`。
